# Requests to the human framework (from The Valley)

Written while building The Valley on HF 2.8.0 (2026-10-19). Each request names what the game does today instead, so the workaround can be deleted when HF answers it. A copy is appended to `docs/game-requests-2026-10-18.md` in the human-framework repository.

1. **A voice's own acts should move trust in that voice.** Voice trust moves only from followed-advice outcomes, insisting and commands. A steward's gift, a seizure, a visit or sending someone away from the door never reaches it, though each is the main thing people judge a steward by. _Today:_ the game calls `adoptVoiceTrust` with a hand-set target and rate for gift, seizure, easing, a visit and a turn-away (engineering assumption), and queues a percept so the episode is remembered.
2. **Material help between households as an HF act.** A hungry house fed by a neighbour after dark is a person's choice (agreeableness, ties, their own store). No HF act moves goods from one person's household to another's. _Today:_ a weekly world rule in the host, gated by the giver's agreeableness and a seeded draw; it is not remembered by anyone.
3. **Recall summaries in the second person.** `recall` returns third-person summaries ("the kahya gave us 6 kile"). A game that lets a person speak a memory back to its actor has to rewrite them. _Today:_ a regex turns "the kahya" into "you" for the elders' lines. A small `voiceOf(episode, toActor)` or a stored addressee form would remove it.
4. **`tellDeath` with listeners whose clocks are past the death.** In a mixed full and routine valley some people have already lived past the minute of a death when the host learns of it; `tellDeath` throws for them. _Today:_ the host catches the error and those people do not hear (engineering fallback). A tolerant mode (deliver the news at the listener's `now`) would fit hosts that advance people unevenly.
5. **`restore` and key order.** `restore(snapshot(p))` holds the same fields in a different key order and drops an empty `family` record, so a plain `JSON.stringify` fingerprint changes across a save. _Today:_ the game sorts keys and drops an empty `family` before fingerprinting. A documented canonical form (or a `fingerprint(person)` helper) would let every game check its saves the same way.
6. **Memory size per person.** About 90 to 100 KB of JSON per person after a month, of which memory is about 42 KB and is not bounded by `Retention`. A valley of 60 people saves at several megabytes. _Today:_ IndexedDB with gzip. A memory bound in `Retention` (episodes kept per actor, or by salience) would make phone saves small.
